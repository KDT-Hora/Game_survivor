# handoff(引継ぎの更新)

次のセッションが、この会話を知らなくても続きから始められるように記録します。

1. `docs/progress/handoff.md` を **上書き** する。見出しは固定:
   - `# 引継ぎ(handoff)`
   - `## 前回の作業` … やったこと(3〜8行)。完了したタスク番号も書く
   - `## 次の作業` … 次にやること(優先順)。最初の一手がわかるように具体的に
   - `## ブロッカー` … 止まっていること。なければ「なし」
   - `## 関連タスク` … 関係するタスク番号
2. `docs/progress/history.md` の **先頭**(見出しの直後)に、`### YYYY-MM-DD` と、今回の作業の記録を3〜10行で追記する。過去の記録は消さない。
3. 関係するタスクごとに、作業ログを残す: `pmg task log N "…"`(`pmg` は、セッション開始時に注入された絶対パスで呼ぶ)。
4. 最後に、更新した内容を2〜3行で報告する。

注意: `docs/decisions.md` は変更しない(決定事項は、壁打ちの結論を人が採用したときにアプリが追記する)。タスクの `status` は編集しない。完了にできるのは人だけで、あなたは `pmg task submit` で提出する。
