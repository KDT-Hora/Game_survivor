# pmg-task

タスクは `docs/tasks/NNNN.md` にあります。**状態(status)を直接編集してはいけません**(編集しても無視され、書き戻されます)。
状態の変更と作業ログは、必ず `pmg task` コマンドで行ってください。`pmg` の場所は、セッション開始時に注入された規則に書かれています。

| やること | コマンド |
|---|---|
| 一覧・内容を見る | `pmg task list` / `pmg task show 12` |
| 着手する | `pmg task start 12` |
| 完了を提出する(人が確認します) | `pmg task submit 12 --note "何をしたか"` |
| 判断が必要で止まる | `pmg task ask 12 --question "聞きたいこと"` |
| 作業ログを残す | `pmg task log 12 "内容"` |
| 新しい作業を提案する | `pmg task propose --title "…" --type 実装 --priority 通常` |

- 完了・差し戻し・回答・中断・取消は、人が画面で行います。あなたからはできません。
- 提出したら、承認されるまで次の作業に進んでかまいませんが、提出済みタスクの完了を前提にしないでください。
- 新しい作業を見つけたら、勝手にファイルを作らず `pmg task propose` を使ってください。
