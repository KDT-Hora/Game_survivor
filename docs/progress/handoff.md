# 引継ぎ(handoff)
## 前回の作業
- 見た目を作り直した。地形・岩・壁・主人公・アイテム・弾はコードで描いたドット絵(`src/app/Art.*`)。地形はランごとに1枚のテクスチャに焼き、水際や石畳の縁取り、草の房や花を入れた。
- 演出を追加(`src/app/Effects.*`): 被弾フラッシュと潰れ、ダメージ数字、撃破の粒、爆発の閃光と粒、画面揺れ、被弾時の赤み、低HPの点滅、カメラの滑らかな追従。
- HUD を整理。最上段に経験値バー、左上に HP と素材と撃破数、下段左に武器スロット(クールダウンとレベルの点)、下段右に建築。倍率などの数値は Tab のステータス画面へ移した。
- タイトル(モードはカード表示。マウスでも選べる)、レベルアップ(カテゴリ色の帯、効果の説明文、出現アニメ)、ポーズ(操作説明+ステータス)、リザルト(建てた壁・押した岩も表示)を作り直した。
- 手応えの変更(`src/game`): 弾と爆弾のノックバック(`weapon.*.knockback`、`enemy.*.knockback_mul`)、アイテムの吸い寄せ(`pickup.magnet_*`)、回復アイテム(`drop_heal_chance`、`pickup.heal_amount`)、敵が同じ点に集まらないよう狙う位置を少し横にずらす、分離を 0.6→1.1。
- 1ステップの出来事を `GameContext::fx`(`FxEvent`)で app 層へ渡す。Step の先頭で消える。進行には使わない。
- `ts_tests` 80件通過(新規5件: 吸い寄せ、回復、ノックバック、fx、結果の集計)。`--zoom N` で拡大撮影できる。
